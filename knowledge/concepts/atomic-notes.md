# Atomic notes

One idea per note, written in your own words, small enough to read in a
minute. Borrowed from the Zettelkasten method, and even more useful with an
agent:

- An agent retrieves and edits **whole files**. A small note means it reads
  only what's relevant and changes can't clobber unrelated content.
- Small notes link precisely: [[wikilinks-and-slugs]] point at one idea,
  not "somewhere in this 2,000-line page".
- Semantic search embeds them cleanly ([[hybrid-search]]): one idea, one
  meaning, one vector neighbourhood.

The linter warns above 300 lines: past that, a note is usually two ideas
([[lint-as-guardrail]]).
